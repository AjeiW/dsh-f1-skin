# dsh-f1-skin F1 四车队皮肤插件实现计划

> **Goal:** 为 DeepSeek Harness Web 构建 F1 四车队皮肤插件：红牛/法拉利/迈凯伦/梅奔四套主题、各队涂装座舱俯瞰图背景、深/浅色跟随 DSH 系统主题、右侧悬浮圆点切换（localStorage 记忆）。

**Architecture:** 一个声明 `dsh.bundle.patch` + `dsh.client.platform:"web"` 的双面 npm 包。Node 半边是空 cordis 插件；客户端半边是手写 web2 惰性 CJS bundle（`window.__ModuleLoader__.load`），通过 `ctx.get("theme").overrideTokens()` 覆盖 78 个 `--dsw-alias-*` token，通过 `ctx.effect()` 注入 CSS 与 DOM 控件。座舱图以 base64 内嵌（服务端只提供单文件 bundle）。

**Tech Stack:** 零运行时依赖（无 React/无构建工具）；仅用 Node 自带 fs 做静态拼装。图片由 AutoGLM 文生图接口生成，sharp（DSH profile node_modules 内）压缩。

## 关键技术事实（已验证）

1. 安装：`dsh plugin --profile web add link:<repo>`（转发 pnpm；bundle 名自动加入 `dsh.profile.bundles`）。
2. 包声明：`exports["./client"]` → `lib/client.js`；`dsh.client.platform: "web"`；`dsh.bundle.patch` → `cordis.patch.yml`。
3. bundle 格式：`window.__ModuleLoader__.load({ id: "dsh-f1-skin", factory(require) { ...; return module.exports } })`，导出 `{ apply, inject }`（cordis 客户端插件面）。
4. 主题服务：`inject: ["theme"]` → `ctx.get("theme")`；`theme.overrideTokens(source, tokens)`，tokens = `{ "--dsw-alias-*": { light, dark } }`；同 source 重复调用 = 整层替换（车队切换）。
5. 主题呈现：ui-layout 的 ThemePresenter 把激活 token 内联到 body；`body[data-ds-dark-theme]` 标记深色。
6. 图片必须内嵌 base64（`/plugins/<id>/client.js` 是唯一 bundle 路由）。
7. 深/浅跟随系统：token 值带 `{light,dark}` 对，官方 Appearance 三档（浅色/深色/跟随系统）继续有效。
8. 新 bundle 层需要 `dsh web` 进程重启才生效；bundle 内容修改只需刷新页面（服务端每次请求重读磁盘）。

## 视觉规范

| 车队 | 底盘色（深/浅） | 品牌主色 | 辅助色 | 座舱图涂装 |
|---|---|---|---|---|
| redbull 红牛 | `#10182E` / `#F2F4FA` | `#FFC800` 黄 | `#D90F0F` 红 | 哑光深蓝 + 黄红饰条 |
| ferrari 法拉利 | `#151113` / `#F9F6F5` | `#DC0000` 红 | `#FFF200` 黄 | 法拉利红 + 黄盾 |
| mclaren 迈凯伦 | `#141519` / `#F6F6F7` | `#FF8000` 木瓜橙 | `#47C7FC` 蓝 | 木瓜橙 + 蓝 |
| mercedes 梅奔 | `#101315` / `#F4F6F6` | `#00D2BE` 石油绿 | `#B4B5B7` 银 | 银黑 + 石油绿 |

- 78 个 `--dsw-alias-*` + `--dsw-specific-sidebar-fill` 全量覆盖；bg-base/sidebar 用 hex8 半透明（约 88%）让座舱图透出。
- `html` 元素背景三层：车队色浅着色 + 深/浅压暗渐变 + 座舱图（cover/fixed）。JS 用 MutationObserver 同步 `body[data-ds-dark-theme]` → `html[data-f1-dark]` 决定浅色滤镜。
- 特效：顶缘 3px 格子旗条、碳纤维纹理、DRS 绿滚动条、Titillium Web 标题字体（@import + 系统回退）、`prefers-reduced-motion` 降级。
- 切换器：右缘竖排 4 圆点（P 房指示灯风），active 发光环，title 提示车队名，localStorage key `dsh-f1-skin:team`，默认 redbull。
