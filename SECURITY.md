# Security Policy

## Supported version

Security fixes target the latest release. The current release candidate is
`0.3.x`, tested with DeepSeek Harness Web `0.1.1-rc.2`.

## Reporting a vulnerability or rights issue

Please use GitHub's private vulnerability reporting on the repository Security
page. Include the affected version, reproduction steps, impact, and any safe
proof of concept. Do not open a public issue for an unpatched vulnerability.

Asset owners may use the same private channel to request correction of an
attribution or removal/replacement of an asset.
